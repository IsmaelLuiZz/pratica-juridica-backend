## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- Git
- Docker & Docker Compose
- Node.js (v20+) ou .NET 8 (conforme a stack escolhida)

### Passo a Passo
1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/pratica-juridica-backend.git

Crie o arquivo .env baseado no .env.example: cp .env.example .env

Suba o banco de dados via Docker: docker-compose up -d
